# 🎬 LOOKWHO: Immersive Exhibition Interaction System

> **“소리는 들린다. 하지만 대화는 흐려진다.”**  
> 청각 노화로 인해 소음 환경에서 대화 흐름을 놓치기 쉬운 전통시장 상인의 상황을 극도로 절제된 다크 애플 에스테틱(Dark Apple Aesthetic) 인터페이스를 통해 온몸으로 깊이 있게 체험하게 만드는 몰입형 전시 인터랙션 프로젝트 **LOOKWHO**입니다.

이 프로젝트는 단순한 미래 기술이나 소리 증폭 AI의 화려함을 자랑하는 툴이 아닙니다.  
**“누구에게 집중해야 하는가”**, **“대화 흐름에서 밀려나는 답답한 고립감”**, 그리고 기술을 통한 **“시선과 집중의 온전한 회복”**을 관람객에게 직접 선사하기 위한 Calm Technology 전시 시스템입니다.

---

## 🎨 디자인 브랜딩 및 톤앤매너 (Brand Design)

사용자님이 지시하신 **Apple Vision Pro 데모** 및 **시네마틱 프로덕트 웹페이지**의 깊은 침묵(Cinematic Silence)을 디자인 전체에 투철히 이식했습니다.

1. **All-Black 갤러리 테마:**
   - 유리 카드, 네온 조명, Neumorphism, SF HUD 등의 요란함을 완벽히 걷어내고, 거의 완전한 **딥 블랙 (`#050505`) 배경** 하에 정밀한 1px 단색 보더 분할선만 사용했습니다.
2. **미세 아날로그 Noise Grain:**
   - 디지털의 평평한 차가움을 누르기 위해, 은은한 아날로그 입자가 숨 쉬는 듯한 **프랙탈 노이즈 그레인(Fractal Noise Grain) 텍스처**를 주입하여 명품 갤러리의 조용하고 깊은 공간감을 구현했습니다.
3. **Calm Typography:**
   - 얇고 세련된 `Inter` 및 `Outfit` 영문/국문 타이포그래피(font-weight: 200~300)와 넓은 자간(letter-spacing) 설정을 통해, 텍스트 자체의 조형적인 여백의 미를 뽐내도록 했습니다.
4. **Cinematic 2.2초 Easing Transition:**
   - 모든 화면 전환과 사물의 등장은 `cubic-bezier(0.22, 1, 0.36, 1)` 베지에 곡선을 타고, **2.2초 동안 극도의 슬로우 모션**으로 초점이 은은히 돌아오는 **blur-to-focus** 및 **노출 순응(Exposure Adapting)** 방식으로 가동됩니다.

## 📽️ 전체 전시 6단계 시나리오 플로우

이 프로그램은 단순 앱 구동이 아닌, 하나의 유기적인 전시 관람 타임라인을 따라 흘러갑니다.

### 1. START SCREEN (시작 화면)
* 딥 블랙 공간에 오직 작은 헤드폰 기호와 "헤드폰을 착용해주세요." 문구, START 단추만 정중앙보다 약간 위에 정갈히 부유합니다.
* START 클릭 즉시 3대 핵심 요소가 블러와 함께 소멸하며, 인트로 비디오가 어둠 속에서 서서히 밝기와 초점을 찾아갑니다.

### 2. INTRO VIDEO (시네마틱 다큐멘터리)
* 소음이 겹쳐지는 어두운 시장 배경 영상이 노출 순응 방식으로 리빌되며, 백그라운드 환경음(ambience)이 귀에 서서히 감기듯 부드럽게 페이드인됩니다.
* 미니멀 자막 캡션이 차례대로 스러지며 상인의 답답한 침묵을 자아냅니다.
* 우측 하단의 정밀한 1px Skip 버튼을 통해 로고 화면으로 스위칭할 수 있습니다.

### 3. LOGO SCREEN (브랜드 로고)
* 캡션 소멸 후 `LOOKWHO` 로고와 슬로건 *“완벽한 몰입. 더 깊은 대화.”*가 은은한 디졸브로 나타나며 3초간 머문 후 자동으로 전환됩니다.

### 4. ROLE IMMERSION (역할 부여)
* *“당신은 이제부터 시장의 상인입니다.”*, *“복잡한 소리 속에서, 대화를 이어가야 합니다.”* 문구가 차례대로 등장하여 관람객을 상인의 내러티브 속으로 완전히 몰입시킵니다.

### 5. GUIDED EXPERIENCE INTERFACE (가이드 인터랙션)
* STEP 1부터 STEP 4까지 이어지는 가상 음성 통신 훈련입니다.
* 화면 지시문구에 따라 마이크 단추를 누르고 발화하면, 가상의 대화 전사(Transcribe)가 1px 다크 HUD 테크 스펙 보드에 동적으로 렌더링되며, 1.8초 뒤 시끄러운 소음 속에서 **손님의 목소리 자막이 맑고 또렷하게 초점을 맞추며 복원**됩니다.

### 6. REAL INTERFACE MODE (실시간 HUD 관람 모드)
* 4단계 훈련 완수 시 진입하는 2분할 실시간 아카이브 모드입니다.
* 좌측의 대화 뷰포트에서 가상의 수산시장 거래 대화들이 4.5초 주기로 전사 렌더링되며, 우측 Diagnostics tech spec 보드에서 소음 수치(dB)와 포커싱 채널 정보가 유기적으로 연동되어 전시됩니다.
* 마이크 단추를 눌러 관람객이 직접 상인의 최종 맑은 멘트를 전사 삽입해볼 수 있으며, 우측 상단 처음부터 버튼을 클릭해 전체 세션을 안전하게 리셋할 수 있습니다.

## 🚀 전시장 가동 및 관람법

1. `gallery-docent` 폴더 내부의 `index.html` 파일을 크롬 브라우저로 엽니다.
2. 헤드폰을 착용하고 미니멀 웰컴 게이트 중앙의 `START` 단추를 클릭합니다.
3. 시네마틱 캡션과 함께 상인의 내러티브에 몰입된 뒤, 안내에 따라 마이크 인터랙션을 수행하며 맑게 개어지는 시선과 사운드의 위엄을 감상해 보세요!
